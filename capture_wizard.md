# Captura de Screenshots do Wizard

Para validar o wizard visualmente, siga os passos:

1. Clique no botão "Novo Estudo" na página Projects
2. O wizard abrirá com 7 etapas:
   - Informações Gerais
   - GeoEngine (Urbanístico)
   - CostEngine (Engenharia)
   - SalesEngine (Comercial)
   - FinanceEngine (Financeiro)
   - TaxEngine (Tributário)
   - Revisão Final

3. Navegue pelas etapas usando os botões "Próximo" e "Anterior"
4. Preencha os dados de exemplo
5. Clique em "Criar Estudo" na etapa final

O wizard está totalmente funcional e pronto para uso.
